Offline spelling review for Windows AAC

Check your spelling before you speak.

Review and edit spelling suggestions for a draft in your AAC speech field. Apply the correction when you’re ready, or copy it back yourself.

Download Windows EXEHow it works

Windows 10 or 11 · 64-bit · English (US) · No installer or account

From draft to reviewed text

  1. 01

    Capture your draft

    Run the EXE. Focus the speech field and press Ctrl+Alt+F8, or choose Capture field and point at it within five seconds.

  2. 02

    Review the suggestion

    Read the proposed correction and change anything you want to keep. Names and specialized words can be flagged incorrectly.

  3. 03

    Apply or copy it back

    Choose Apply to AAC if the field supports direct editing. Otherwise, use Copy correction and paste it into your AAC app.

Before you try it

Will it edit the TD Snap Message Window directly?

Direct editing requires a plain-text field that exposes a writable Windows UI Automation value. It has not been verified on a physical Tobii Dynavox device. Try a short unsent draft first. If editing isn’t available, copy the draft from TD Snap, choose Paste draft and Check spelling in the spellchecker, then copy and paste the reviewed text back into TD Snap.

Does it speak, record, or send my draft?

It uses the installed Windows English (US) spelling dictionary and works offline without recording or transmitting drafts. It never presses Speak. If your AAC app is set to speak when text is inserted, that setting still applies.

What happens if the draft changes?

The spellchecker won’t overwrite a draft that changed after capture. Undo AAC fix can restore the previous text if the field still contains the correction. Use your AAC app’s own editing tools for drafts with symbols or formatting you need to preserve.

Why might Windows show a warning?

The EXE is unsigned. Windows may show a warning for a new unsigned app. The spellchecker does not need administrator privileges.
