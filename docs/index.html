From draft to reviewed text

  1. 01

    Dwell on Spell Check

    After the one-time setup, write a draft in TD Snap and choose the Spell Check button on your AAC keyboard page.

  2. 02

    Review the suggestion

    Read the proposed correction and change anything you want to keep. Names and specialized words can be flagged incorrectly.

  3. 03

    Use it or keep your draft

    Choose Use correction to update the linked AAC Message Window, or Keep original to go back without changing the draft.

Before you try it

How do I set up the eye-gaze button?

In the EXE, choose Link AAC field and point at the TD Snap Message Window when prompted. In TD Snap's editor, add a Spell Check button with the Launch Application action. Use the EXE as the application and enter --check under Advanced Command Line Arguments. See full setup instructions.

Will this work on my device?

Direct editing requires a linked, writable plain-text field and gaze controls that can click Windows buttons outside TD Snap. It has not been verified on a physical Tobii Dynavox device. Test with an unsent draft first. If linking or editing is blocked, the gaze workflow reports the limitation instead of using the clipboard.

Which spelling engines can I use?

Windows Spell Checking is the default and needs no download. The spelling engine menu also offers NeuSpell BERT, NeuSpell SC-LSTM, BART English Spelling Correction, T5-large-spell, SAGE mT5 Large, and Spell Correct Transformer.

The first spelling check with an optional local model downloads its files and the shared CPU runtime. After that, the engine works offline. If a model fails during gaze review, choose Use Windows spelling to check the same draft. For the two large T5 models, 16 GB RAM is recommended. The others are the lighter choices for 8 GB PCs. Always review the suggested changes.

Can I use DeepSeek or Grok?

Yes. Select the cloud engine in the desktop app, enter your own API key, then choose Save key. The key is encrypted for your Windows account. Each check asks you before sending that draft to the selected provider. In gaze review, you can choose Use Windows spelling instead to stay offline. Provider charges and data policies apply.

Does it speak or record my draft?

Windows spelling and the six local models do not send drafts anywhere. Model downloads do not include drafts. The app does not record drafts or press Speak. If your AAC app is set to speak when text is inserted, that setting still applies.

What happens if the draft changes?

The spellchecker won’t overwrite a draft that changed after capture. Choose Keep original in the gaze review to leave the draft untouched. Use your AAC app’s own editing tools for drafts with symbols or formatting you need to preserve.

Why might Windows show a warning?

The EXE is unsigned. Windows may show a warning for a new unsigned app. The spellchecker does not need administrator privileges.
